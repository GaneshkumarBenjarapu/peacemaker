EXERCISE 7 - DOCKER COMPOSE
============================================================

1. Create folder.

mkdir compose-lab
cd compose-lab

2. Create docker-compose.yml with:

services:
  web:
    image: nginx:latest
    ports:
      - "8080:80"
    depends_on:
      - db
  db:
    image: postgres:15
    environment:
      POSTGRES_USER: demo
      POSTGRES_PASSWORD: demo
      POSTGRES_DB: demo_db
    volumes:
      - db-data:/var/lib/postgresql/data
volumes:
  db-data:

3. Run.

docker compose up -d
docker compose ps
docker compose logs
docker volume ls
docker network ls

4. Open http://localhost:8080

5. Stop and remove.

docker compose down
docker compose up -d

6. Remove containers and volumes.

docker compose down -v

IMPORTANT COMPOSE COMMANDS
